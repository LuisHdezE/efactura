# To-Be Target

## Visión
El objetivo para eFactura, aplicando la `Technology Preservation Constraint`, es **eFactura hardened within its existing .NET ecosystem**.

- Mantener ASP.NET Core 8.0.
- Mantener Entity Framework Core.
- Limpiar el acoplamiento arquitectónico aislando `ApplicationCore`.
- Fortificar la seguridad, eliminando secretos de configuración y asegurando JWT y CORS.
- Estandarizar el Error Contract y las entidades duplicadas.
